## Topics Covered

1. **Two Uses of Adjectives**
   - **Attributive** (Noun-এর পূর্বে বসে) – called Epithet  
     Example: *a good boy*  
     Only attributive: *former, olden*
   - **Predicative** (Verb-এর পরে বসে)  
     Example: *The boy is good*  
     Only predicative: *alone, asleep, afraid, alike, aloof, alive, ashamed, awake, aware, content*

2. **Classification of Adjectives** (7 groups)
   - Proper (from Proper Nouns): Indian, British, Vedic, Islamic
   - Qualitative (quality/state): honest, poor, brave, large, foolish
   - Quantitative / Numeral (quantity/number): some, many, little, any, first, few, all, whole
   - Distributive: each, every, either, neither
   - Demonstrative: this, that, such, same
   - Interrogative: which, whose, what
   - Emphasising: own, very

3. **Degrees of Comparison**
   - Positive → Comparative → Superlative
   - One-syllable: add *-er / -est* (with exceptions for final *e*, *y*, and consonant doubling)
   - Longer adjectives: *more / most* or *less / least*
   - Two-syllable ending in *-le, -y, -er, -ow*: often treated like one-syllable

4. **Irregular Comparison**
   - bad/evil/ill → worse → worst
   - good → better → best
   - little → less/lesser → least
   - many/much → more → most
   - old → older/elder → oldest/eldest
   - late → later/latter → latest/last
   - far → farther → farthest
   - and others (fore, hind, near, nigh, etc.)

5. **Special Rules & Tips**
   - Comparatives usually + *than*; selection uses *the ... of*
   - Latin comparatives (*inferior, junior, prior, senior, superior*) + *to*
   - Never use double comparatives/superlatives (*more happier* ❌)
   - Some adjectives cannot be compared: *perfect, unique, round, square, eternal, chief, supreme*, etc.
   - Absolute Superlative (a most interesting book)
   - Use of *that* in comparisons to avoid absurdity
   - Adjectives used as Nouns (*the rich*, *the brave*)
   - Nouns used as Adjectives (*gold chain, summer vacation*)
